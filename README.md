# 🧠 اتاق فکر چندعاملی (Multi-Agent Research Lab)

یک اپلیکیشن Streamlit برای تولید گزارش‌های تحلیلی و راهبردی با همکاری دو ایجنت هوش مصنوعی مستقل — همراه با نظارت انسانی (Human-in-the-Loop) روی نتیجه‌ی نهایی.

🔗 **دمو زنده:** [Multi-Agent Research Lab](https://deep-research-agent254.streamlit.app/)

## ✨ ویژگی‌ها

- **🔎 ایجنت محقق (Researcher Agent):** موضوع کاربر را به یک کوئری تمیز و مناسب گوگل تبدیل می‌کند، با استفاده از [Serper API](https://serper.dev) جستجوی زنده انجام می‌دهد و از نتایج، یک یادداشت تحلیلی مستند (با ذکر منبع برای هر نکته) استخراج می‌کند.
- **🧐 ایجنت سردبیر (Editor Agent):** بر اساس یادداشت‌های محقق، یک گزارش راهبردی رسمی و ساختاریافته با چهار بخش ثابت تولید می‌کند:
  - چکیده اجرایی
  - جدول سناریوها و آمار کلیدی
  - تحلیل روندها
  - نتیجه‌گیری و پیشنهاد راهبردی
- **👤 نظارت انسانی (Human-in-the-Loop):** امکان ثبت فیدبک و بازنویسی گزارش توسط سردبیر تا رسیدن به خروجی دلخواه.
- **🛡️ تشخیص گزارش‌های ناقص:** بررسی خودکار برای نشانه‌های قطع‌شدن گزارش (مثل جدول یا جمله‌ی نصفه) و هشدار به کاربر برای بازتولید.
- **📥 خروجی HTML رسمی:** تبدیل گزارش نهایی به یک سند HTML تیره، راست‌چین (RTL) و قابل دانلود، آماده برای ارائه یا آرشیو.
- **🌐 رابط کاربری کاملاً فارسی و راست‌چین**، بهینه‌شده برای فونت‌های فارسی.

## 🏗️ معماری

```
ورودی موضوع کاربر
        │
        ▼
  ساخت کوئری گوگل (LLM)
        │
        ▼
  جستجوی زنده (Serper API)
        │
        ▼
  ایجنت محقق → یادداشت تحلیلی مستند
        │
        ▼
  ایجنت سردبیر → گزارش راهبردی ۴بخشی
        │
        ▼
  بازبینی انسانی (فیدبک اختیاری) ──► بازنویسی توسط سردبیر
        │
        ▼
  خروجی HTML رسمی و قابل دانلود
```

## 🧰 پیش‌نیازها

- Python 3.9+
- یک کلید API از [Groq](https://console.groq.com) (برای مدل زبانی)
- یک کلید API از [Serper](https://serper.dev) (برای جستجوی گوگل)

## ⚙️ نصب و راه‌اندازی

```bash
# ۱. کلون کردن ریپازیتوری
git clone https://github.com/<your-username>/<repo-name>.git
cd <repo-name>

# ۲. ساخت محیط مجازی (اختیاری ولی پیشنهادی)
python -m venv venv
source venv/bin/activate   # ویندوز: venv\Scripts\activate

# ۳. نصب وابستگی‌ها
pip install -r requirements.txt
```

سپس یک فایل `.env` در کنار `app.py` بسازید و مقادیر زیر را در آن قرار دهید:

```env
GROQ_API_KEY=your_groq_api_key_here
SERPER_API_KEY=your_serper_api_key_here
```

> ⚠️ فایل `.env` هرگز نباید کامیت شود. این پروژه از قبل در `.gitignore` این فایل را نادیده می‌گیرد.

## ▶️ اجرا

```bash
streamlit run app.py
```

سپس آدرس نمایش‌داده‌شده در ترمینال (معمولاً `http://localhost:8501`) را در مرورگر باز کنید.

## 📦 وابستگی‌های اصلی

| کتابخانه | نقش |
|---|---|
| `streamlit` | رابط کاربری وب |
| `langchain-groq` | اتصال به مدل زبانی روی Groq |
| `langchain-core` | ابزارها و پیام‌های LangChain |
| `langchain-community` | Wrapper مربوط به Serper API |
| `google-search-results` | وابستگی جستجوی گوگل |
| `duckduckgo-search` | جستجوی جایگزین (در صورت نیاز توسعه‌ی آینده) |
| `markdown` | تبدیل گزارش مارک‌داون به HTML |
| `python-dotenv` | بارگذاری متغیرهای محیطی از `.env` |

## 📝 نحوه‌ی استفاده

1. موضوع گزارش موردنظر را در ستون سمت راست وارد کنید و روی «فعال‌سازی ایجنت محقق» بزنید.
2. پس از تولید یادداشت‌های محقق، ایجنت سردبیر به‌طور خودکار پیش‌نویس اول گزارش را می‌سازد.
3. در صورت نیاز، فیدبک یا دستور اصلاحی خود را در بخش «نظارت انسانی» وارد کرده و روی «بازنویسی توسط سردبیر» بزنید.
4. گزارش نهایی را با دکمه‌ی «دانلود گزارش رسمی (HTML)» دریافت کنید.

## ⚠️ نکات امنیتی

- کلیدهای API را هرگز در کد یا فایل‌های کامیت‌شده قرار ندهید — همیشه از `.env` استفاده کنید.
- اگر کلیدی به‌صورت تصادفی افشا شد (مثلاً در یک اسکرین‌شات، پیام یا کامیت اشتباهی)، بلافاصله آن را در پنل مربوطه (Groq / Serper) باطل و جایگزین کنید.
